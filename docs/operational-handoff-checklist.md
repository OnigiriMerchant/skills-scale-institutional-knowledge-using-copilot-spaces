# Operational Handoff Checklist

Owner: SRE / On-call Lead

Purpose: Ensure production readiness and clear handoff from delivery to operations/support.

Before handoff
- [ ] Runbooks for new functionality created and reviewed
- [ ] Pager and escalation paths updated with expected on-call owners
- [ ] Dashboards and alerts created and sanity-checked
- [ ] Run a game-day or tabletop if the change is high-risk
- [ ] Verify backups, rollbacks, and failovers are documented

Handoff meeting
- [ ] Delivery team walks SRE/support through new feature behavior
- [ ] Confirm expected traffic patterns and capacity implications
- [ ] Walk through troubleshooting steps and known issues

Post-handoff
- [ ] Support tickets or known issues list created
- [ ] Knowledge base and internal docs updated
- [ ] Schedule a follow-up checkpoint after 48–72 hours
