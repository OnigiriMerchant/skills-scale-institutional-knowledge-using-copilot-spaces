# Measurement & Instrumentation Checklist

Owner: Data Analyst / Measurement Owner

Purpose: Ensure that success metrics and instrumentation are in place before release.

Before coding
- [ ] Define primary and secondary success metrics in the one-pager
- [ ] Identify events and properties required for measurement

Before merge
- [ ] Instrumentation added and validated in a dev/staging environment
- [ ] Event schemas registered (where applicable)
- [ ] Data quality checks in place for critical metrics
- [ ] Dashboards created and shared with stakeholders

Post-release
- [ ] Run analysis to validate metric behavior against expectations
- [ ] Document interpretation and next steps based on the data
